Derivation (not an API assertion): deltaNorth=target.x-player.x,
deltaWest=target.y-player.y; artwork rotation=atan2(deltaWest,deltaNorth)-facing.
Positive rotation points left; zero points up. Sixteen independent target/facing cardinal
expectations, wraparound and arrival test this offline. Actual client orientation remains
NOT TESTED. At zero distance the arrow hides and says Arrived · 0 yd; no quest completion.

The sampler accumulates elapsed, samples at >=0.05 seconds, discards excess time, and
creates no addon tables/closures or formatted strings before the throttle. Target vectors
and conversions are cached; target/map/world/instance transitions invalidate conversions.
API-returned vectors may allocate each tick. Stub tests cannot establish client CPU or memory.
Invalid/secret/unavailable data hides stale output with Position unavailable; sampled retry
allows recovery. Hidden/disabled/combat/failed parts stop sampling. Combat defers scale.

Map pin is explicit. Foreign/unknown markers are preserved; observed replacement/removal
revokes ownership and step refresh never reacquires it. Matching coordinates have no engine
identity token: an unobserved replacement at identical coordinates is indistinguishable.
Own yards never reads C_Navigation or C_SuperTrack state.
