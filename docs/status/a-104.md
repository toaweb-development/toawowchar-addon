  deterministic controlled primitive Lua literal in a temporary file, then load it

  This proves the test serialization/recreated-session boundary, not the WoW client's
  actual SavedVariables disk writer. It is stronger than Env.relog retaining a pointer.
  Test-only loadfile executes exclusively the harness-generated literal; no shipped
  eval/loadstring, file IO or network. No permanent new capture fixture is claimed.
  Existing legacy→3 and unknown/newer DB no-write regressions remain green.
